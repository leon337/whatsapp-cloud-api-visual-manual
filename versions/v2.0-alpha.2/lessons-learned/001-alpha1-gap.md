# Lesson 001 — A visual manual is not just documentation with screenshots

## Observation from Alpha 1

Adding real screenshots improved evidence, but did not satisfy the intended learning experience.

## Gap

The learner still had to infer:
- what to do first;
- exactly where to look;
- whether the action succeeded;
- what to do when the screen differed;
- when to move forward.

## Generalizable lesson

For future MCF visual manuals, screenshots are evidence, not the teaching mechanism by themselves.

A guided manual needs:
1. explicit action;
2. visual focus;
3. expected result;
4. validation;
5. contextual recovery;
6. progressive explanation.

This lesson is candidate input for MCF-BUILD-VISUAL-MANUAL.

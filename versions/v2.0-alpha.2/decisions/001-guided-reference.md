# Decision 001 — Guided + Reference modes

## Context

Alpha 1 materialized the technical content and real public documentation screenshots, but it did not yet create the feeling of having a specialist beside the learner.

## Decision

Alpha 2 uses two complementary modes:

- Guided Mode: one task at a time, progress, help and completion state.
- Reference Mode: complete non-linear manual.

Each major step gains progressive depth:
- Make it with me;
- Understand;
- Engineering.

## Why

A single long documentation page cannot serve beginner learning and experienced lookup equally well. The two modes reuse the same source material without forcing two separate products.
